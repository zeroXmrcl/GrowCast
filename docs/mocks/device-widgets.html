Devices beside Climate

Wheelbank is first. Everything else is a new language, same cell height. Left is always the climate picker.

B · Wheelbank

Your pick so far. Seven skinny climate wheels, same detents / mask / hairlines as Temp.

H · Flap

Split-flap Solari board. Name above, value on a hinged leaf. Same mechanical family as the picker, but airport instead of iOS wheel.

I · Odometer

Car-counter drums. One glyph per window, split through the middle. OFF is grey digits, EMPTY is red.

J · Needles

Seven analog meters. Needle angle is duty. Alerts pin to the left in red, they do not peg the scale.

K · LCD

One instrument screen. Everything is type on a green phosphor panel, like the GGS itself. Faults go salmon.

L · Rockers

Physical switches in the picker band. Up = drawing, down = off, red up = fault. Hardware next to the wheels.

M · Sideways

Same picker, rotated. States run left–right with a center window. If the vertical wheelbank feels cramped, this is the other axis.

N · Digits

Wheelbank without the wheel. Plain climate numbers, ghost rows above and below so it still occupies the three-line band.

O · Trace

Seven micro oscilloscopes. Amplitude is duty. EMPTY is a dashed red flatline, not a tall wave.

P · Seals

Wax-seal discs. The value lives inside the circle, the name under it. A stamp, not a lamp or an icon tile.
