Devices, 1:1 with Climate

Same live row, same padding, same 6rem instrument. Values drift so the motion is the real one.

R · Turbine

N1 gauges in the climate band. Ticks, a balanced needle that spools, and a digital window. A fault returns the needle to the stop and drops a flag over the window.

B · Wheelbank

Seven climate wheels. Same mask, same hairlines, same easing as the picker. A fault scrolls to EMPTY / HOT / FULL instead of filling the scale.

P · Seals

The value is the stamp. The ring is duty and eases with the workspace curve. EMPTY is a red word in an empty ring — it never reads as 100%.

O · Trace

A scope per actuator. Amplitude is duty and glides when the level changes. Off is a dim baseline. EMPTY is a flat red line, not a wave.

Q · Reactor

A power-channel bay. Segments light from the bottom. A trip does not fill the column — the annunciator drops over a dark stack.

S · Sap

Seven capillaries. The column is duty, and a bead keeps circulating inside it. EMPTY is a clot at the bottom of a dry tube.
